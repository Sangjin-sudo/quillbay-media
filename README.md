# quillbay-media

Static media host for Quillbay Labs Instagram carousels (JPEG card images served through GitHub Pages so the Instagram Content Publishing API can fetch them).

- `en/YYYY-MM-DD/NN.jpg`: Quillbay Labs (English data and space explainers)
- `ko/YYYY-MM-DD/NN.jpg`: Korean philosophy card news
- `privacy.html`: privacy policy for the publishing app

Charts are drawn in code from cited public data. Quotes on Korean cards are original translations of public-domain texts. Sources are listed on each carousel.
